# 🔍 Domain-All: 멀티모달 비전 자가 검수 엔진 (Vision-Critic)

이 모듈은 AI가 생성한 웹 UI, 상업용 그래픽, 혹은 펫 모션을 **'시각적으로 직접 관찰하고 비판(Critic)하여 스스로 고치는'** 자율 피드백 루프의 안전장치와 정량적 평가 기준을 정의합니다.

---

## 1. 2단계 하이브리드 검수 아키텍처 (Gemini 4 Argon 피드백 반영)

비전 LLM을 무작정 호출하여 발생하는 토큰 낭비와 응답 지연을 방지하기 위해, **기계식 1차 검수 ➜ 멀티모달 2차 검수**의 2단계 파이프라인을 강제합니다.

```
[결과물 렌더링 / 스크린샷 캡처]
         │
         ▼
[1단계: 기계식 사전 검증 (0.05초)] ──(탈락)──> 즉시 CSS 수정 (API 호출 0회)
 - DOM 텍스트 오버플로우/잘림 검사
 - WCAG 4.5:1 명도 대비 계산
         │ (통과)
         ▼
[2단계: Vision AI 심미성 검수 (Max 2회)] ──(90점 미만)──> 1회 교정 후 재캡처
 - 해부학/텍스트 형태 왜곡 검수
 - AI 슬롭(보라 네온, 과도한 광택) 잔존 검수
         │ (90점 이상 합격)
         ▼
[최종 결과물 output/ 확정]
```

---

## 2. 정량적 채점 체크리스트 (100점 만점 기준)

Vision AI는 캡처된 이미지를 보고 아래 4개 항목을 채점하며, **총점 90점 이상일 때만 최종 합격** 처리합니다.

| 검수 항목 | 배점 | 감점 기준 |
| :--- | :---: | :--- |
| **1. 텍스트 가독성 & 무결성** | 30점 | 글자 뭉개짐(-15), 한글 자모 분리(-20), 배경과의 대비 부족(-10) |
| **2. 안티-슬롭(AI 티 제거)** | 25점 | 촌스러운 보라/네온 그라데이션 잔존(-15), 플라스틱 피부 질감(-10) |
| **3. 여백 및 레이아웃 질서** | 25점 | 8px 그리드 이탈(-10), 요소 간 시각적 충돌/답답한 패딩(-15) |
| **4. 컴포넌트 마감 완성도** | 20점 | 1px 경계선 누락(-5), 어색한 라운딩 반경 불일치(-10) |

---

## 3. 무한 루프 차단 안전장치 (Hard-Stop Rule)

> [!CAUTION]
> **Max Retries = 2회 엄수**  
> AI가 자기 결과물을 끝없이 고치는 무한 교정 루프(Infinite Critique Loop)와 토큰 낭비를 방지하기 위해, **자가 교정 재시도는 최대 2회까지만 허용**됩니다.

* **1차 검수 90점 미만**: 문제점 1~2개를 특정하여 프롬프트/CSS 수정 후 2차 캡처 진행.
* **2차 검수 90점 미만 (하드스탑)**: 추가 재시도를 즉각 중단하고, 현재까지의 결과물과 점수 리포트를 사용자에게 제출하며 **"2차 시도 완료 (현재 85점). 이 상태로 채택하시겠습니까, 아니면 특정 부분을 직접 지시하시겠습니까?"**로 선택권을 인계합니다.

---

## 4. 폐기물(B컷) 관리 정책 (Staging Archive)

* **저장 위치**: 프로젝트 루트 하위 `.cache/rejected/` (또는 `.gemini/antigravity/scratch/rejected/`)
* **파일명 규칙**: `{timestamp}_{domain}_attempt_{N}_score_{pts}.png`
  * 예: `20261016_banner_attempt_1_score_75.png`
* **보관 이유**: AI 평가 기준에서는 탈락했더라도 사람의 주관적 미감에는 매력적인 'B컷'일 수 있으므로 즉시 삭제하지 않고 격리 보관합니다.
* **자동 정리**: 프로젝트 완료 승인 시 사용자의 명시적 확인을 받아 임시 폴더를 안전하게 비웁니다.
